## Official usage notes
- The official `RSS Feeds` page explicitly publishes two machine-readable feed endpoints: one for news posts and one for changed datasets.
- The `news/rss` feed is generated by Ghost and includes `<ttl>60</ttl>`, a self-link, item metadata, and article links.
- The dataset feed at `/api/hub/search/de/feeds/datasets.atom` includes `rel="first"`, `rel="next"`, and `rel="last"` links, confirming page-based feed traversal.
- The dataset Atom feed also exposes `rel="alternate"` links to dataset pages and optional `rel="enclosure"` links for downloadable resources when an entry has one.

## Canonical endpoints confirmed from the official site
1. `GET /news/rss`
   - Base URL: `https://www.data.gv.at`
   - Purpose: return the portal news RSS feed
   - Query parameters: none shown on the reviewed official RSS page or live feed response
   - Live confirmation:
     - returned an RSS 2.0 document titled `data.gv.at - News`
     - returned `generator: Ghost 5.107`
     - returned `atom:link href="https://www.data.gv.at/news/rss/" rel="self"`
     - returned `<ttl>60</ttl>` plus standard `<item>` entries with `title`, `link`, `description`, `pubDate`, and `dc:creator`

2. `GET /api/hub/search/de/feeds/datasets.atom`
   - Base URL: `https://www.data.gv.at`
   - Purpose: return the changed-datasets Atom feed for the German portal view
   - Query parameters:
     - `page` - optional page number for feed traversal; confirmed from live `next` and `last` links in the reviewed Atom document
   - Live confirmation:
     - returned an Atom feed titled `data.gv.at - Atom Feed`
     - returned `rel="alternate"` pointing to `http://www.data.gv.at/api/hub/search/search?filter=dataset`
     - returned `rel="self"`, `rel="first"`, `rel="next"`, and `rel="last"` links
     - returned dataset `<entry>` elements with `id`, `title`, `summary`, `updated`, `alternate`, and optional `enclosure` links

## Pagination, filtering, and format notes
- `GET /news/rss` is a plain RSS 2.0 feed with no documented query parameters on the reviewed official page.
- `GET /api/hub/search/de/feeds/datasets.atom` is an Atom feed with explicit page navigation through `page=` links.
- The reviewed dataset Atom feed exposed `page=2` as the next page and `page=6993` as the last page during this run.
- The official feeds are XML-first surfaces rather than JSON REST endpoints.
