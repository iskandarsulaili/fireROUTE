## Authentication

- The spec also does not attach auth requirements to any individual operation.

## Common request/response conventions
- The homepage explicitly links to the official API host at `https://api.filterlists.com/`.
- The Swagger UI titles the service `FilterLists Directory API` and describes it as `An ASP.NET Core API serving the core FilterList information.`
- The OpenAPI document is hosted under `/v1/openapi.json`, but live endpoint checks show the actual JSON routes are mounted at the host root rather than under `/v1`.
- Responses are JSON collections or JSON objects describing languages, licenses, lists, maintainers, software, syntaxes, and tags.

## Manually confirmed endpoint inventory
1. `GET /languages` - list languages targeted by filter lists
2. `GET /licenses` - list filter-list licenses
3. `GET /lists` - list filter lists
4. `GET /lists/{id}` - retrieve one filter list by numeric ID
5. `GET /maintainers` - list maintainers
6. `GET /software` - list software consumers
7. `GET /syntaxes` - list syntax definitions
8. `GET /tags` - list tags

Manual route count confirmed: **8**.

## Parameters and request-body notes

## Rate limits

## Error and response notes
- The OpenAPI document publishes `200 OK` for all eight routes.
- `GET /lists/{id}` additionally documents `404 Not Found`.
- The OpenAPI schemas show typed JSON resource objects. Representative confirmed fields include:
  - `/languages`: `id`, `iso6391`, `name`
  - `/lists`: `id`, `name`, `description`, `licenseId`, `syntaxIds`, `languageIds`, `tagIds`, `maintainerIds`
  - `/lists/{id}`: all of the above plus detail fields such as `viewUrls`, `homeUrl`, `issuesUrl`, `forumUrl`, `emailAddress`, and relationship ID arrays
- A live check of `GET /lists/301` returned the detailed EasyList object and confirmed that `viewUrls` is an array of objects with `segmentNumber`, `primariness`, and `url`.

## Response format notes
- The API serves `application/json; charset=utf-8`.
- Collection endpoints return top-level arrays of objects.
- Resource relationships are expressed by integer ID arrays rather than embedded full objects.
- The Swagger UI and OpenAPI are accurate about route shape, but the spec's hosting path (`/v1/openapi.json`) should not be mistaken for the runtime base path of the JSON endpoints.

## Important usage notes
- The homepage and API UI are both first-party and mutually reinforcing: the website links to the API, and the API UI links back to the website and project wiki pages.
- Consumers should use `https://api.filterlists.com` as the runtime origin for the eight JSON endpoints documented above.
- The API appears read-only from the public spec; no create/update/delete routes are exposed.
- Because the official docs provide no pagination or throttling rules, fireROUTE should treat bulk synchronization conservatively even though the endpoints are public.
